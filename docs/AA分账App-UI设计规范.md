## 1. 设计理念

**一句话**：让用户感觉像"在一本可爱的速写本上记账"。

| 关键词 | 设计表达 |
|---|---|
| 手绘 | 所有边框是不规则的"手抖"线条；图标是圆头涂鸦线条；偶有笔触抖动 |
| 可爱 | 熊猫吉祥物"团团"穿插全书；小星星♡涂鸦点缀；圆润造型 |
| 轻松 | 暖米色纸张底、糖果色点缀；金额用大号手写体；空状态有搞笑文案 |
| 纸感 | 卡片像便签/贴纸贴在纸上；纸胶带、图钉、印章元素 |
| 亲切 | 文案口语化（"等TA们摊钱咯~"）；按钮有实感按压反馈 |

**设计红线**：
- 装饰不影响金额可读性（金额永远是画面主角，用大号手写数字）
- 涂鸦线条厚度统一 2.5px，圆头端点
- 颜色不超过「纸张 + 墨色 + 3个糖果色」的节奏

## 2. 吉祥物：团团🐼

```
     /一\          团团 —— 涂鸦小熊猫
   /  一   \        · 头顶一根"财"字呆毛（招财）
  (  ●  ●  )       · 吃小笼包长大，圆滚滚，腿短
   (   ▽   )       · 手里常拿一支铅笔（记账本命）
    / |  |  \
     团  团         使用场景：空状态插画、净额卡片陪伴、结算成功庆祝、
                   引导提示、消息推送头像、占位图
```

**设定要点**：
- 所有特征为**简笔涂鸦线条**（非写实），腮红两个椭圆，眼睛两个圆点+高光
- 情绪变体：开心（弯眼）、发呆（豆豆眼）、着急（蒸汽）、庆祝（撒花）
- 不许出现在：账单金额上方（挡字）、按钮内部
- 配色：黑白+粉腮红+柠檬黄道具

## 3. 色彩系统

### 3.1 基础色板

| 色名 | HEX | 用途 | 占比 |
|---|---|---|---|
| 纸张米 | `#FBF3E4` | 全局背景（速写本纸） | 55% |
| 深纸米 | `#F4E8D3` | 卡片垫底/浅色块 | 15% |
| 墨色 | `#443A32` | 线条/文字/图标 | 20% |
| 淡墨 | `#8A7A68` | 次要文字 | — |
| 纸胶带柠檬 | `#FFD166` | 卡带装饰/高亮 | 2% |
| 珊瑚橙 | `#FF8C69` | **主色**（主按钮、选中态、应付金额） | 5% |
| 薄荷绿 | `#8FCE9F` | 应收金额、成功态、已付 | 2% |
| 天空蓝 | `#7EC4E8` | 信息/链接/次要强调 | 1% |
| 藕芋紫 | `#B79CE0` | 装饰/分类点缀 | 1% |
| 草莓粉 | `#F49CB4` | 腮红/心形装饰 | 1% |
| 荧光笔黄 | `#FFE8A3` | 手绘高亮划重点 | 1% |

### 3.2 语义色（重要）

| 语义 | 颜色 | 示例 |
|---|---|---|
| ✅ 应收（别人欠我） | 薄荷绿 `#8FCE9F` | +¥120.00 |
| ⭕ 应付（我欠别人） | 珊瑚橙 `#FF8C69` | -¥86.50 |
| ⚪ 已结清 | 淡墨 60% | 划线+印章"清" |
| 警告/催款 | 草莓粉 `#F49CB4` | 催款角标 |

### 3.3 配色规则

- 一屏主色 ≤ 1 个，点缀色 ≤ 2 个
- 所有颜色加 **8% 左右的"纸感"**：做法是在色块上叠 3% 透明度噪点纹理
- 金额永远用**墨色或语义绿/橙**，不用彩色渐变色字

## 4. 字体系统

本项目不设置任何字体回退方案，也不设额外排印规则；严格按下述分级字体系统执行：

| 用途 | 字体 | 字号区间 |
|---|---|---|
| App 标题 / 导航栏 | 站酷快乐体（ZCOOL KuaiLe）或系统圆体 | 22–26px |
| 金额大字（视觉主角） | 龙藏体（Long Cang）手写 | 36–44px |
| **货币符号与正负号（¥ / + -）** | **JetBrains Mono（手绘/标准风格统一）** | 随金额字号 ×0.47（符号 ×0.72） |
| 正文内容 | 手写感楷体（站酷快乐体 14px，或系统圆体）搭配墨色渲染 | 14–16px |
| 辅助小字 | 与正文字体一致，使用淡墨色 | 11–12px |
| 英文 / 数字点缀 | Caveat 或 Patrick Hand 手写字体 | 手写 |

**执行标准**：所有规则以严格还原 `docs/ui-demo/index.html`（Demo）为最终执行标准——各页面具体字号、字体与 Demo 逐页保持一致（如金额大字 42px、群账 34px、列表行金额 22–24px 等均沿用 Demo 内联值）。**货币符号 ¥ 与正负号 + / - 两种字体风格均使用 JetBrains Mono**；设置页切换「标准风格」时，金额数字同步切换 JetBrains Mono、其余文字切换 Noto Sans SC。

## 5. 纹理与材质

| 材质 | 做法 | 用在哪 |
|---|---|---|
| 速写本纸底 | `#FBF3E4` + 极淡圆点网格（点距 24px，5% 墨色） | 全局背景 |
| 手绘边框 | `border: 2.5px solid #443A32` + 不规则圆角：`border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px`（可反向变化产生不同"手抖"效果） | 卡片/按钮/输入框 |
| 涂鸦阴影 | 实心偏移阴影：`box-shadow: 3px 3px 0 #443A32`，按压时位移 1px | 按钮/卡片 |
| 纸胶带 | 半透明彩条（柠檬黄/薄荷绿），两端锯齿，贴在卡片顶部中央，旋转 ±3° | 卡片装饰 |
| 印章 | 双线圆圈 + 印章字（如 ✅已结清 / 📢已催款），旋转 -8° | 状态标签 |
| 划重点 | 荧光笔黄粗笔画背景（`background: linear-gradient(transparent 55%, #FFE8A3 55%)`） | 关键数字/文案 |
| 手绘下划线 | 不规则弯曲 SVG 线 | 链接/标题 |

## 6. 图标与插画

### 6.1 图标规范

- **涂鸦线性图标**：2.5px 墨色描边、圆头端点、轻微抖动曲线（不是复制粘贴的规整几何图形）
- 尺寸档位：Tab 26px / 列表 24px / 行内 18px
- 常用图标（全部手绘 SVG）：房子·人像群·铅笔·铃铛·人像·钱袋·小票·相机·星星·爱心·印章·箭头

### 6.2 插画规范

- 简笔线条 + 平涂淡彩（不超过4色）
- 空状态插画统一：`团团 + 场景道具`（如团团爬梯子数钱、团团抱小票叹气）
- 插画不做投影、不做渐变，保持"纸贴画"感

### 6.3 图标素材系统（docs/pic → app/assets/icons）

界面 icon/插画素材统一由 `docs/pic/` 维护，**文件命名约定：文件名 = 对应 emoji**（如 `🔍.png`、`⚙️.png`、`🧾.png`），新增素材只需按此命名放入目录。

**处理流水线**（一条命令，可重复执行）：

```bash
powershell -ExecutionPolicy Bypass -File scripts/process-icons.ps1
```

处理步骤：① 白色背景洪水填充抠透明 → ② 仅保留最大连通域（清除"AI生成"水印等孤立像素）→ ③ 内容包围盒裁剪居中 → 512×512 透明底 PNG → `app/assets/icons/*.png`；同脚本将 `app图标.png` 同步到 Android 全密度启动图标（传统 + 自适应）。

**语义命名映射**（emoji 文件名 → 资产名，脚本内 `$map` 维护）：⚙️→settings、🔔→notify、👥→group、✏️→edit、📢→broadcast、📤→export、🧾→receipt、🪙→coin、💌→mail、📮→inbox、📱→phone、💻→laptop、🔑→key、🔒→lock、🔐→locked、📡→signal、🎉→party、🔥→flame、🌙→moon、😴→sleep、☀️→sun、📒→notebook、🎧→headphone、🎒→bag、🌸→flower、🥺→sad、🕵️→detective、✨→sparkle、🍲→food、👑→crown、💡→bulb、📅→calendar、⏰→clock、📊→chart、📋→clipboard、📜→scroll、📦→box、📷→camera、🔍→search、🧮→abacus。

**Dart 侧接入**：

- `AaIconImage(asset, size)`：通用图标组件（`app/lib/widgets/common.dart`）
- `AaAppBar` 支持 `headIcon`（标题前图）与 `iconImage`（右侧图）；列表行支持 `leadImage`（行首图）
- `EmptyState(artImage:)`：空状态插画使用素材图；`SectionTitle(emojiImage:)`：分组徽标使用素材图
- 素材按语义逐一替换界面 emoji 插画与系统图标（接入清单见 `docs/开发进度.md`）

## 7. 组件规范

### 7.1 卡片（便签卡）

```
┌────────────── 纸胶带(旋转-3°) ──────────────┐
│  左上角固定"小图钉"或胶带                   │
│  标题（手写体）+ 内容                      │
│  不规则手绘边框 + 2.5px 墨线               │
│  轻微旋转 ±0.5°（3张以内不齐平才可爱）      │
└────────────────────────────┘
```
- 状态卡（净额卡）：背景深纸米 + 团团趴在角上 + 荧光笔标数字

### 7.2 按钮

| 形态 | 样式 |
|---|---|
| 主按钮 | 珊瑚橙填充 + 墨色手绘边框 + 2px 纸纹理 + `box-shadow:3px 3px 0`；文字白色手写+略微上移；按压下沉 2px 且影子变小（"按下去"手感） |
| 次按钮 | 白底/纸底 + 墨线边框 + 涂鸦阴影 |
| 文字按钮（小） | 手绘下划线 + 星星点缀 |
| 图标按钮 | 圆形涂鸦描边，hover 时画"嘎吱"震动动画 |

### 7.3 输入框

- 样式："填空题"——只有一条**手抖下划线**，不做方框（登录/标题）
- 金额输入：超大手写数字 + 下划线 + 右侧"算盘"小子件
- 聚焦态：下划线变珊瑚橙，上浮发光笔笔触

### 7.4 标签与印章

- 分类标签：圆头小胶囊 + 图标（🍜餐饮 🚕交通 🏠住宿 🛍购物 🎮娱乐）
- 状态印章：`✅已结清` `📢已催2次`，旋转-8°，双线描边

### 7.5 Tab栏 / 弹层 / Toast / 空状态

| 组件 | 规范 |
|---|---|
| Tab栏 | 白纸底+顶部墨线；图标手绘，选中项 = 珊瑚橙涂鸦圆包围 + 图标上扬跳动；中央 ➕ 是放大版铅笔图标，凸起于栏上 |
| 弹层（Bottom Sheet） | 从底部滑出，顶边是"撕纸"锯齿边；左上图钉 |
| Toast | 手绘横幅：小纸片 + 团团头像 + 文案；2s 后像纸条飘走 |
| 空状态 | 团团插画 + 手写大字文案（如"还没有账单，记一笔开启AA之旅叭～"）+ 主按钮 |

### 7.6 图表风格

- 统计图表一律**手绘柱状图**：柱子是深浅交替的蜡笔质感，柱顶画小❤或小⭐
- 环形图：用「甜甜圈+巧克力豆」造型，扇区变换时豆豆滚动

## 8. 动效规范

| 场景 | 动效 | 时长 |
|---|---|---|
| 页面切换 | 像翻动速写本页面（轻微旋转+平移），非左右滑动 | 300ms |
| 保存成功 | 涂鸦对勾"画出来"（path 描边动画）+ 团团撒花 | 600ms |
| 结算生成 | 转账箭头逐笔画线 + 钱袋抖出金币 | 800ms |
| 按钮按压 | 下沉 2px + 阴影收缩 + 轻微旋转 | 120ms |
| Tab 切换 | 图标蹦跳（弹簧曲线）+ 涂鸦圈描边 | 250ms |
| 催款发送 | 纸飞机"飞出"动画 | 500ms |
| 通知到达 | 铃铛晃动 + 弹消息纸片 | 400ms |

原则：所有动效带**橡皮筋感**（弹性曲线），禁线性生硬；单个动效 ≤ 800ms。

### 8.1 动效实现要点（开发者版）

| 动效 | 实现方案 | 参数 |
|---|---|---|
| 对勾描边 | SVG `stroke-dasharray/dashoffset` 动画 | 600ms · ease-out |
| 结算箭头 | 同描边法，逐条路径绘制 | 500ms/条 · 交错120ms |
| 铃铛晃动 | `transform-origin` 顶部 + rotate keyframes | 600ms · 晃动2次 |
| 纸飞机飞出 | **不均匀手绘关键帧**（旋转抖动"逐帧感"）+ 虚线笔触轨迹线（`stroke-dashoffset` 边飞边描出） | 1000ms · 关键帧近似linear |
| 金币抛入罐 | 涂鸦SVG金币 + 旋转抛掷关键帧（-360°）+ 虚线抛掷轨迹 + ✦星光闪烁 | 550ms/枚 · 交错150-200ms |
| 印章落下 | scale 2.2→1 + rotate -24°→-8° | 450ms · 弹性曲线 |
| Tab 弹跳 | translateY -5px 弹簧 | 280ms |
| 按钮按压 | translate 2px + 阴影收缩 | 120ms |
| 页面切换 | rotate -1.2° + translateX 14px + fade | 300ms |
| Toast 飘走 | translateY + fade，像纸条刮走 | 250ms |

**通用参数**：
- 弹性曲线：`cubic-bezier(.34,1.56,.64,1)`（所有"落下/弹起"类动效必须用它）
- 展开/划出类动效用 `ease-out`；离场类用 `ease-in`
- 震动/晃动类波动次数 ≤ 2 次，忌癫痫式高频
- **手绘动效原则**：用"不均匀关键帧"模拟手绘师逐帧动画（轨迹点错落、轻微旋转抖动），忌标准缓动的"机械感"；飞行/抛掷类必须配**虚线笔触轨迹线**并随运动描出，不能让对象"消失/突然出现"
- 尊重系统「减弱动态」设置：开启后除 Toast/印章外全部退化为淡入淡出
- 所有动效不允许阻塞操作，触摸即响应（可中断）

## 9. 空状态与异常态设计

### 9.1 空状态总表

| 场景 | 插画 | 主文案 | 动作按钮 | 出现在 |
|---|---|---|---|---|
| 群组列表空 | 团团坐地数零钱 | 还没有群组，拉上小伙伴开个AA局吧～ | [＋创建群组] | P20 |
| 账单列表空 | 团团趴在摊开的账本上 | 账本空空如也，记一笔吧！ | [✏️ 记一笔] | P11/P12 |
| 搜索结果空 | 团团拿放大镜瞪大眼睛 | 翻来覆去没找到…换个关键词？ | [清空关键词] | P60 |
| 消息中心空 | 团团戴耳机打瞌睡 | 安静的一天～ 没有新消息 | [去记一笔] | P40 |
| 已清账庆祝 | 团团撒花 | 本群已清账！两不相欠啦 🎉 | [再来一笔] | P23/P25 |
| 无待催款 | 团团举✓牌 | 没有欠款要催，大家都超靠谱！ | [返回] | P26 |
| 网络错误 | 团团头顶 WiFi 断线 | 网络开小差了…检查一下再试试 | [🔄 重试] | 全局 |
| 加载失败/500 | 团团摔四脚朝天 | 服务器打了个盹，稍后再试 | [🔄 重试] | 全局 |

### 9.2 空状态规范

- 插画统一：`团团 + 场景道具`，放卡片上半区居中；简笔线条+平涂淡彩（≤4色），有背景氛围元素（星星/小云/线条风）
- 主文案：手写体 16px 墨色，关键词用荧光笔黄高亮（最多1处）
- 辅助文案：12px 淡墨色，≤20字，可以加"～"
- 按钮：每空态最多 1 个主按钮或 1 个 ghost 按钮 + 可选文字链
- 空状态不隐藏 Tab栏，用户随时能离开；页面滚动高度 ≥ 60% 屏

### 9.3 异常态规则

| 类型 | 处理方式 |
|---|---|
| 表单校验 | 按钮置灰 + 行内红章提示（如"金额要大于0哦"）；不弹窗打断输入；错误印章旋转 -8°、草莓粉 |
| 权限不足 | 直接 Toast："只有群主可以这么做哦"；操作按钮置灰 |
| 破坏性操作 | 手绘纸片**二次确认弹窗**（图钉+撕纸边+团团"确认吗？"），确认钮=红色蜡笔按钮，取消=ghost |
| 内容已删除/失效 | 打开即显示"这张小票已经烧掉了🔥"空态 + [返回列表] |
| 登录过期 | Toast"登录过期，再登录一下呗～" → 跳 P02，保留已填账户名 |

### 9.4 文案风格红线

- 口语化、可爱但不幼稚："等TA们摊钱咯~" ✓ / "您的账单已生成" ✗
- 空状态**禁止**出现"无数据""暂无内容""加载失败"这类系统语言
- 金额不出现在空状态文案里；感叹号每屏 ≤ 1 个
