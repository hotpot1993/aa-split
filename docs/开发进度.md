**本轮发现并修复的真实缺陷**：
4. **updateProfile 会话回退**：`AuthRepository.updateProfile` 从 SharedPreferences 读取 token 并 `_saveSession` 回写，会把 ApiClient 会话"切走"（多账户/测试切换时）→ 修复为只更新本地 user 缓存、不动认证 token（[auth_repository.dart](../app/lib/data/repositories/auth_repository.dart)）
5. **Android 联调清单缺失**：主 manifest 无 INTERNET 权限、无明文 HTTP 允许（Android 9+ 默认禁止 http）→ `AndroidManifest.xml` 添加 `INTERNET` + `usesCleartextTraffic`（生产接 HTTPS 后应移除）
6. **真机链接**：`gradle.properties` 增加 `kotlin.incremental=false` 规避 Windows 下 Kotlin 增量缓存映射文件损坏（虚拟机/安全软件环境常见）
7. **启动会话恢复失效**（真机重启必掉登录页）：`SplashScreen._go` 真实模式从未调用 `AuthController.restore()` → 补上（await restore 后按登录态跳转）（[splash_screen.dart](../app/lib/screens/splash/splash_screen.dart)）
8. **弱网误清会话**：`restoreSession` 对任何异常都 `_clearSession` → 改为仅 401 清除（[auth_repository.dart](../app/lib/data/repositories/auth_repository.dart)）
9. **群页无创建入口**（非空列表时）：`groups_screen` AppBar 增加 ➕ 创建群组（原来只有空状态按钮）
10. **群详情两处布局溢出**：成员横向条（SizedBox 54→66）与群总账成员卡（84→96），手写体行高大于估算（[group_detail_screen.dart](../app/lib/screens/groups/group_detail_screen.dart)）
