🔐 隐私政策

⭕
生效日期：2026-08-24 · 版本 V1.0.0 · 首次发布（无更新内容）
本政策适用于「AA分账」所提供的信息收集、使用、存储、共享与保护等活动。我们非常重视您的个人隐私与数据安全。本 App 为记账提醒工具，不托管资金、不代收代付，不涉及支付、贷款、理财等任何资金交易与金融服务。
一、我们收集哪些信息
遵循"最小必要"原则，仅收集服务所必需的信息；不收集通讯录、位置、短信、通话记录及金融账户信息。
您主动提供：账号信息（账户名 + 密码，bcrypt 哈希存储）、昵称/头像/签名、安全问题、群组与账单数据、凭证图片（存储于服务端）。
自动收集：极光推送设备标识（用于通知）、基础日志（IP、设备型号、系统版本，用于安全与排查）。
二、我们如何使用这些信息
提供与维护核心服务；账号与安全（登录、找回密码、风控审计）；消息推送（可随时关闭）；改进与排查（基础日志）；履行法律义务。
不会用于无关目的，不会用于广告投放或画像分析。
三、如何共享、转让与公开披露
不出售、不出租、不主动向第三方共享个人信息，仅在以下情形进行：
· 第三方服务（极光推送 JPush）：唯一接入的 SDK，仅用于账单 / 催款提醒等通知；
· 法律法规要求时依法配合披露；
· 保护合法权益所必需时在合理必要限度内处理。
四、第三方 SDK 清单
· 极光推送 JPush（jpush_flutter，深圳市和讯华谷信息技术有限公司）：推送通知；收集设备标识、系统信息、推送注册 ID 等；共享：是（仅用于推送）
· image_picker（系统相册 / 相机）：凭证图片；仅主动选择时使用；共享：否（本地能力）
