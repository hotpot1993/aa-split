# Google Play Data Safety 表单填写建议

> 本文件用于在 Google Play Console 填写 **Data safety（数据安全）** 表单时逐项选择建议答案，供开发者提交时对照使用。
> **整体判断**：本 App 为「记账与提醒工具」，**不托管资金、不代收代付、无支付/贷款/理财功能**，且**不接入任何广告 SDK 或统计 SDK**，仅接入 **极光推送（JPush）** 用于通知提醒。因此其收集的数据类型**少且单一**，可安全地将其定位为「以一种明确、符合用途的方式收集少量必要数据，且主要用于提供核心记账服务」。

**重要提醒**：提交 Google Play Data safety 时，凡收集 / 共享的数据类型须在隐私政策、以及应用内「数据安全」相应位置如实披露，并与本文件保持一致。

---

## A. 总览问题

**Q1. 应用是否收集或共享任何类型的用户数据？**
> 建议：**是（收集）**。
> 理由：App 通过「自定义账户名 + 密码」登录，会收集账号信息、记账数据（群组/账单/结算/通知）与用户主动上传的凭证图片；极光推送 SDK 会采集推送所需的设备标识信息。

**Q2. 数据是否加密传输？**
> 建议：**是**（App 与服务端之间采用 HTTPS 加密传输）。

**Q3. 是否提供数据删除机制？**
> 建议：**是**（支持删除单条数据 / 删除我的数据入口，以及账号注销；注销后数据删除或匿名化）。

**Q4. 是否承诺遵守数据安全承诺（Play Policy）？**
> 建议：**是**，并勾选「数据已加密传输」。

## B. 数据是否收集（收集 → 是 / 否）

### 1. 个人信息（Personal Info）
| 数据 | 是否收集 | 是否共享 | 说明 |
|---|---|---|---|
| 姓名（Name） | **否** | 否 | 不收集真实姓名 |
| 邮箱地址（Email address） | **否** | 否 | 不收集邮箱；客服邮箱仅在您主动联系时使用未进入后台统计 |
| 用户 ID / 账户名（User IDs / Account name） | **是** | 否（不共享） | 自定义账户名用于登录与识别 |
| 电话号码（Phone number） | **否** | 否 | 不收集 |
| 设备 / 其他 ID（Device or other IDs） | **是** | **是（仅与极光推送共享）** | 推送注册 ID / 设备标识，仅用于推送 |

> 说明：账号信息用于登录、账号找回与安全保障，属核心功能所需；**不用于广告或画像**。

### 2. 财务信息（Financial Info）
| 数据 | 是否收集 |
|---|---|
| 用户财务信息（如银行卡、支付账户、信用记录） | **否** |
| 交易记录 / 购买记录 | **否** |
| 收入 / 支出记录以外的"金融"类：| —— |

> 理由：本 App **不托管资金、不代收代付、无支付/贷款/理财功能**，不采集任何金融账户、银行卡、信用卡信息。用户在 App 内录入的「金额」仅为记账用途的文本/数值，不属于金融财务敏感信息，且完全由用户自愿输入。

### 3. 照片和视频（Photos and Videos）
| 数据 | 是否收集 | 是否共享 | 说明 |
|---|---|---|---|
| 照片（Photos） | **是** | 否（不共享） | 用户主动上传的账单凭证图片，存储于服务端用于对账留痕 |
| 相册 / 媒体库内容 | **否**（仅用户主动选择的图片） | 否 | 不后台读取，仅在用户执行「上传凭证」时按需读取 |

### 4. 消息 / 通讯（Messages）
> 建议：**否**（App 不提供独立聊天；消息中心仅展示账单/通知类系统消息）。

### 5. 联系人（Contacts）
> 建议：**否**（不收集通讯录 / 联系人）。

### 6. 位置信息（Location）
> 建议：**否**（不收集精确或模糊位置）。

### 7. 应用活动（App activity / usage）
> 建议：**否**（不采集行为画像、广告追踪、崩溃事件等用于外部用途；如需调试可仅保留本地日志，不纳入 Data safety 收集范畴）。

### 8. 网络 / 性能 / 崩溃日志
> 若 App 采集崩溃日志 / 诊断数据用于自身改善：建议选择**是（收集、不共享）**，并仅勾选「诊断 / 崩溃」用途属 App 自身用途。若未采集则选**否**（更简化）。

### 9. 其他数据（Other / health, fitness, etc.）
> 建议：**否**（不涉及健康、财务敏感等其它类别）。

## C. 数据用途（Collected Data - Purpose）

收集的数据建议勾选以下用途（如实填写）：
- **App 功能（App functionality）**：登录、记账、结算、提醒、统计等核心功能。
- **账户管理（Account management）**：账号注册、登录、找回、注销。
- **安全（Security）**：登录限流、账号保护、审计日志。
- **通知（Notification）**：通过极光推送发送账单 / 催款提醒。

> 不勾选：广告（Advertising）、个性化 / 画像（Personalization）——本 App 不进行广告投放与用户画像。

## D. 数据是否与他人共享（Data Shared）

| 数据类型 | 是否共享 | 与谁共享 | 原因 |
|---|---|---|---|
| 设备或其他标识（推送注册 ID / 设备标识） | **是** | 极光推送（JPush） | 仅为向您发送账单 / 催款通知 |
| 其他所有数据 | **否** | — | 不向任何第三方共享 |

> 若后续接入其它 SDK（广告 / 统计），须重新如实申报。

## E. Data safety 一句话判断理由（可填入「是否需要更多披露」等说明处）

> 「AA分账（AA Split）为记账与提醒工具，**不托管资金、不代收代付、无支付/贷款/理财功能**，不采集金融账户信息。App 仅收集为用户提供记账服务所必需的账号信息、记账数据、用户主动上传的凭证图片，以及极光推送为发送通知所需的设备标识；**不接入任何广告或统计 SDK**，不采集位置、通讯录、短信、通话记录。除将设备标识共享给极光推送以完成通知功能外，不向任何第三方共享数据。所有传输经 HTTPS 加密，并提供数据删除与账号注销机制。因此将其定位为『以明确用途收集少量必要数据、主要用于核心记账功能』的轻型应用。」
