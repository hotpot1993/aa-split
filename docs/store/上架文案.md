**应用简介（≤200 字符）**

```
和朋友 AA 分账的记账 App。多群组记账、四种分摊方式、最少转账笔数结算方案、催款提醒在手绘风里轻松算清帐。不托管资金、不代收代付，转账走微信/支付宝。
```

**应用描述（600–1000 字，满足上限）**
```
【轻松算清每一笔 AA 账】

AA分账 是一款和朋友 AA 分账的记账 App。无论是聚餐、旅行、租房还是共同活动，都能帮大家把账算得明明白白，又不必当面开口催钱，避免尴尬。

【主要功能】

· 多群组记账：可创建多个群组，设置群名、添加成员，朋友可通过邀请码加入，各自独立记账、互不干扰。
· 四种分摊方式：均摊、按人数、按比例、自定义金额，灵活适配各种分账场景。
· 最少转账笔数结算：自动计算让转账笔数最少的结算方案，谁该给谁、给多少一目了然。
· 催款提醒：一键提醒未付款的朋友，温和又高效。
· 账单凭证拍照上传：消费凭证拍照留存，账目可追溯。
· 定期账单：每日自动生成本期账单，习惯性记账不落下。
· 收支统计：图表直观展示收支情况，账目心中有数。
· 数据导出：支持 xlsx / csv 导出，方便对账与归档。
· 消息中心与实时推送：账单、催款动态实时到达（SSE + 极光推送）。
· 手绘风 UI与吉祥物「团团」：可爱轻松的风格，让记账这件事不再枯燥。支持深色模式。

【关于资金安全】

本 App 不托管资金、不代收代付，用户间转账请使用微信 / 支付宝自有功能。App 内不包含支付、贷款、理财等功能，不涉及任何资金交易与金融服务。用户之间的真实转账行为由用户自行承担。

【账号与数据】

支持自定义账户名 + 密码登录；账号、账单、凭证等数据仅用于本 App 的记账服务。我们重视你的隐私，详见《隐私政策》与《用户协议》。
```

**版本说明 v1.0.0（首次发布，≤500 字）**
```
v1.0.0（2026-08-24）· 首次发布

新增：
· 多群组记账，邀请码加入，独立管理
· 四种分摊方式：均摊 / 按人数 / 按比例 / 自定义金额
· 最少转账笔数结算方案
· 催款提醒、消息中心与实时推送
· 账单凭证拍照上传、定期账单自动生成
· 收支统计图表、xlsx / csv 数据导出
· 手绘风 UI + 吉祥物「团团」，支持深色模式

说明：首次发布，暂无已知问题。感谢使用，欢迎反馈。
```
