## 一、我们收集哪些信息

我们遵循"最小必要"原则收集信息，仅收集为您提供服务所必需的信息。本 App **不收集**通讯录、位置信息、短信、通话记录以及金融账户信息。

### 1. 您主动提供的信息
| 信息类别 | 具体内容 | 收集方式 |
|---|---|---|
| 账号信息 | 自定义账户名、登录密码（以 bcrypt 哈希形式存储，我们无法看到您的明文密码） | 您注册时填写 |
| 个人资料 | 昵称、头像、个性签名 | 您主动填写 / 上传 |
| 安全问题 | 找回密码的安全问题及答案（用于账号找回） | 您注册 / 设置时填写 |
| 内容数据 | 群组、成员、账单、分摊明细、结算、通知等记账相关数据 | 您在使用过程中产生 |
| 凭证图片 | 您主动上传的消费小票 / 账单凭证图片（存储于服务端） | 您上传时采集 |

### 2. 我们自动收集的信息
| 信息类别 | 具体内容 | 用于 |
|---|---|---|
| 推送设备标识 | 极光推送（JPush）SDK 采集的设备标识（如推送 Registration ID、设备信息等） | 用于向您发送账单 / 催款提醒等通知 |
| 基础日志信息 | IP 地址、设备信息（型号、系统版本等）、操作日志 | 用于安全保障、故障排查与日志审计 |

### 3. 我们不收集的信息
我们**不收集**您的通讯录、地理位置、短信、通话记录、金融账户信息、银行卡信息等敏感个人信息。您可在本 App 内自由记账，但所有资金往来均通过微信 / 支付宝等第三方完成，与本 App 无涉。

## 二、我们如何使用这些信息

1. 提供与维护核心服务：实现多群组记账、四种分摊、最少转账笔数结算、催款提醒、凭证管理、定期账单、收支统计、数据导出等功能。
2. 账号与安全：用于账号注册、登录、找回密码、安全管理、风控审计，保障账号与数据安全。
3. 消息推送：通过极光推送向您发送账单变更、催款问候等通知（您可随时通过系统设置或在 App 内关闭通知）。
4. 改进与排查：用于统计、故障排查、安全防护和服务质量提升（基础日志）。
5. 履行法律义务：在法律要求或为保护您与他人合法权益所必需时，依法处理相关数据。

我们**不会**将您的信息用于与本政策无关的目的，也不会将其用于广告投放或画像分析。

## 三、我们如何共享、转让与公开披露信息

我们**不会**出售、出租或主动向任何第三方共享您的个人信息，**仅**在以下情形下进行：

### 1. 第三方服务（极光推送）
本 App 接入的唯一第三方 SDK 为**极光推送（JPush）**，用于向您发送账单 / 催款提醒等通知。为实现推送功能，极光 SDK 会收集并处理必要的设备信息（如设备标识、推送注册 ID、系统信息等），该等信息仅用于消息推送。极光推送收集与处理的个人信息详见其官方《隐私政策》。

> **说明**：图标 / 图片选择使用系统相册能力（`image_picker`，本地能力，不上传至第三方），SharedPreferences 仅在本地保存登录态，均不向第三方传输您的个人信息。

### 2. 法律法规要求
在法律法规、司法或行政主管机关依法要求时，我们会在法定范围内配合披露。

### 3. 保护合法权益
为保护您或其他用户的合法权益、防止欺诈或安全事故所必需时，我们会在合理必要的限度内处理信息。

除上述情形外，我们不会向任何第三方共享、转让或公开披露您的个人信息。

## 五、信息的存储与保护

1. **存储地点**：您的数据存储于【开发者主体名称】自行部署的服务器（正式上架前请在更新说明或此处注明实际部署地）。
2. **传输安全**：App 与服务端之间的数据传输采用加密传输（HTTPS），防止数据在传输过程中被窃取或篡改。
3. **密码保护**：您的登录密码以 **bcrypt 单向哈希**形式存储，我们无法获取或还原您的明文密码。
4. **访问控制**：账单仅参与者 / 群主可读，未加入群组的请求会被系统视为不存在，以防止数据探测。
5. **备份与容灾**：服务端采用数据库每日快照备份，以保障数据可用性。
6. **安全审计**：对删除账单、解散群组等关键操作留存操作日志。
7. **您应尽的义务**：请妥善保管您的账户名、密码，不要向任何人透露。因密码保管不当造成的损失由您自行承担。

## 六、信息的保存期限

1. 您的个人信息仅在实现本政策所述目的所必需的期限内保留；超出必要期限后，我们将予以删除或匿名化处理。
2. 当您**注销账号**后，我们将在合理期限内删除或匿名化处理您的个人信息，或依法在法定保留期届满后予以删除。
3. 依据法律法规需要留存的数据（如为满足审计、争议解决等法定义务），我们会在法定保留期限内保存，并在期限届满后删除。
