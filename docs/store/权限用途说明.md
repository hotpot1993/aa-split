# AA分账 · 权限用途说明

> 本说明用于各应用商店（华为 / 小米 / OPPO / vivo / 应用宝 / Google Play）提交时填写「权限用途」，以及回答审核人员对权限申请动机的询问。
> 本 App **不含**广告 SDK、统计 SDK、支付 SDK，仅接入「极光推送 JPush」用于通知提醒。所有权限均遵循「最小必要」原则，仅在为您提供服务所必需时使用。

**安全声明**：本 App 为记账提醒工具，**不托管资金、不代收代付**，无支付、贷款、理财功能。除必要的网络与推送外，本 App 不调用通讯录、定位、短信、通话记录、金融账户等敏感权限。

## 权限清单与用途

| 权限名 | 用途 | 申请时机 | 拒绝后的影响 |
|---|---|---|---|
| `INTERNET`（网络访问） | 与服务器通信，同步群组 / 账单 / 结算 / 通知数据，接收实时推送与催款消息 | App 首次启动时由系统自动授予 | **拒绝则 App 无法联网，无法登录、无法同步数据与收发消息，核心功能不可用**。此为应用基础权限。 |
| `POST_NOTIFICATIONS`（Android 13+ 通知运行权限） | 发送账单变更、催款提醒、结算通知等系统通知 | 需要发送通知时（首次开启 / 登录后申请，也可在系统设置中开启） | **拒绝后收不到账单与催款提醒通知**；不影响记账、结算等功能本身，您仍可主动打开 App 查看消息中心。 |
| `WAKE_LOCK`（唤醒锁） | 保证推送到达时能唤醒设备以显示通知，提升送达及时性 | 由极光推送 SDK 在初始化时申请 | 拒绝可能影响离线推送的及时到达；不影响 App 前台使用。 |
| `RECEIVE_BOOT_COMPLETED`（开机自启） | 设备开机后恢复推送服务连接，保证通知持续可达 | 由极光推送 SDK 在部分场景申请 | 拒绝后设备重启可能导致推送连接需手动打开 App 恢复；不影响已有数据与记账功能。 |
| `VIBRATE`（震动） | 收到通知 / 提醒时提供震动反馈 | 由推送 / 通知流程触发申请 | 拒绝后通知仅展示不震动；不影响其他功能。 |
| 相机（CAMERA，按需） | 拍摄账单凭证 / 消费小票照片，用于记账留痕 | 用户主动点击「拍照上传凭证」时按需弹出 | 拒绝后无法拍照上传凭证，但不影响手动录入账单与记账功能。 |
| 相册 / 媒体（图片选择，按需） | 从相册选择账单凭证图片上传 | 用户主动点击「从相册选择」时按需弹出 | 拒绝后无法从相册选图上传凭证，但不影响记账功能。 |

## 补充说明

1. **网络权限（INTERNET）** 为应用联网的基础权限。由于本 App 的登录、群组、账单、结算、统计、消息推送等均需与服务器交互，该权限为必需权限。
2. **通知权限（POST_NOTIFICATIONS）** 属于 Android 13+ 动态运行权限，由您在需要时授权；本 App **不会**在未征得您同意的情况下强行申请，您可在系统设置中随时开启 / 关闭。
3. **相机 / 相册** 属于「在使用时按需申请」的权限，仅在您主动执行上传凭证操作时触发，**不会**在后台静默访问您的相册，也不会读取您未选择的内容。
4. 本 App **不申请**通讯录、定位、短信、通话记录、麦克风、存储空间等与记账无关的敏感权限。
5. 第三方 SDK 权限：**极光推送 JPush** 会声明其推送所需的必要权限（如网络、唤醒、开机自启、震动等），用于实现通知送达，详见其官方说明。

## 各市场「权限用途」一句话文案（可直接复制）

- **INTERNET**：用于与服务器同步群组 / 账单 / 结算 / 通知数据，并接收实时推送。
- **POST_NOTIFICATIONS**：用于发送账单变更、催款提醒等通知。
- **WAKE_LOCK / RECEIVE_BOOT_COMPLETED / VIBRATE**：由极光推送 SDK 用于保证通知的可靠送达与提醒。
- **相机 / 相册**：用于用户主动拍摄或选择账单凭证图片上传（按需申请）。

## 附：release 包最终权限（aapt 实测，2026-08-26）

上架包 `dist/release/app-release.apk`（v1.0.2 / 2003）实测 uses-permission 共 11 项（含 2 项自定义/厂商）：

| 权限 | 来源 |
|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 网络与推送心跳 |
| `POST_NOTIFICATIONS` | 通知（Android 13+ 运行时） |
| `CAMERA` | 扫码加入群组（mobile_scanner）+ 凭证拍照（image_picker，运行时按需） |
| `WAKE_LOCK` / `RECEIVE_BOOT_COMPLETED` / `VIBRATE` | 推送离线送达 |
| `com.aasplit.app.permission.JPUSH_MESSAGE` / `com.huawei.android.launcher.permission.CHANGE_BADGE` | 极光 SDK 与华为角标（自定义/厂商） |
| `com.aasplit.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | AndroidX 自动声明（安全加固，非采集类） |

**已通过 `tools:node="remove"` 强制移除 SDK 声明的高敏权限**（上架合规关键）：
`ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` / `ACCESS_BACKGROUND_LOCATION`（定位）、
`READ_PHONE_STATE`（设备信息）、`QUERY_ALL_PACKAGES`（应用列表）、`READ/WRITE_EXTERNAL_STORAGE`（存储）。
`CAMERA` 仅由扫码入群与凭证拍照在用户主动操作时按需申请，不做后台访问。
**升级极光/扫码 SDK 后务必复查**（`aapt dump permissions`）。
