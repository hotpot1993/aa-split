## 3. 资质清单（阻塞项，需线下办理）

1. **开发者账号**（各渠道独立实名注册；企业主体资质最强，个人主体部分渠道限制类目）。
2. **计算机软件著作权（软著）** —— 国内 5 大渠道基本必需；个人开发者可尝试「软著`或者`承诺函」（华为/应用宝对个人放宽）。
   - 软著材料可用：本仓库即交付物（源码 + 说明文档），名称建议 `AA分账软件 V1.0`。
3. **ICP 备案 / APP 备案号** —— 自 2023 年起国内应用商店强制「App 备案」；域名 `hotpot1993.top` 已备案的前提下，在「工信部 ICP/IP 地址/域名信息备案管理系统」为 App 办理应用备案，取得备案号填入各渠道。
4. **华为「安全漏洞检测/隐私合规」自检**：按后台《隐私政策》要求勾选收集清单（与我们文档一致：账号/昵称/头像/群账单/凭证图片/推送标识）。
5. Google Play：开发者注册费 $25/次；**Play App Signing** 开启后上传 AAB（用我们已签名 AAB 即可，Play 会再托管签名）。
6. App Store：Apple Developer Program $99/年；若无 Mac 打包环境，可先用 Android 双端上架，iOS 后补（工程已含 iOS 图标/名称/隐私描述）。

## 4. 隐私政策 & 用户协议部署（2 分钟）

已提供自包含 HTML（单文件、内嵌样式），部署到 VPS（宝塔 nginx，与 API 同机）：

```bash
# 在 VPS 上（web 根目录，以宝塔默认 /www/wwwroot/ 为例；或任意 nginx 可访问目录）
sudo mkdir -p /www/wwwroot/aa-split-docs
sudo cp 隐私政策.html /www/wwwroot/aa-split-docs/privacy.html
sudo cp 用户协议.html /www/wwwroot/aa-split-docs/agreement.html

# nginx 站点增加（aa-split-api.conf 所在 vhost 或独立 vhost）：
#   location /privacy.html  { alias /www/wwwroot/aa-split-docs/privacy.html; }
#   location /agreement.html { alias /www/wwwroot/aa-split-docs/agreement.html; }
sudo nginx -t && sudo systemctl reload nginx
```

验证 URL（Cloudflare 已有 A 记录 `api.hotpot1993.top`）：
`https://api.hotpot1993.top/privacy.html` / `https://api.hotpot1993.top/agreement.html`
全部渠道「隐私政策链接」填这两个地址。

> 中国商店要求隐私政策可访问且**声明 App 备案号**；文中【App备案号】占位符务必替换。

## 5. 最终权限清单（release 包 aapt 实测，上架材料以此为准）

| 权限 | 用途 | 分类 |
|---|---|---|
| INTERNET | 与后端 API 通信 | 网络 |
| ACCESS_NETWORK_STATE | 断网/恢复判断（推送心跳） | 网络 |
| ACCESS_WIFI_STATE | 极光推送网络状态 | 网络 |
| POST_NOTIFICATIONS | Android 13+ 通知（记账/催款提醒） | 运行时申请 |
| WAKE_LOCK / RECEIVE_BOOT_COMPLETED / VIBRATE | 推送离线送达 / 通知震动 | 系统 |
| com.aasplit.app.permission.JPUSH_MESSAGE | 极光推送自定义权限（SDK 自带） | 系统 |

> ⚠️ 已通过 `tools:node="remove"` 强制移除 SDK 带入的：定位（3 项）、READ_PHONE_STATE、QUERY_ALL_PACKAGES、
> READ/WRITE_EXTERNAL_STORAGE。**若后续升级极光 SDK，请复查合入权限**（`aapt dump permissions`）。
