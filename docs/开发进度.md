## 四、关键修复记录（质量事件）

1. **幽灵转账 bug**（结算正确性）：部分已付账单会把已付参与人再算成欠款 → `summarizeBalances` 增加 `paid` 排除 + 垫付人应收扣减已付份额；新增 2 例回归单测
2. **Prisma Client 过期**：schema 更新后未 regenerate → `BillInclude/BillGetPayload` 缺失、大量隐式 any → 重新 `prisma generate`
3. **@nestjs/bullmq v10 API 变更**：无 `@Process()` 装饰器 → 继承 `WorkerHost` 实现 `process(job)`
4. **MinIO putObject 参数错位**：mimetype 被传给 size 位 → 补 `buffer.length` + metadata
5. **regular-bills dto 导入路径**：少一层 `../` → 修正为 `../../bills/dto/create-bill.dto`
6. **测试符号约定**：assertValid 的净额方向写反（应收=正）→ 修正并保留零和校验

**本轮发现并修复的真实缺陷**：
4. **updateProfile 会话回退**：`AuthRepository.updateProfile` 从 SharedPreferences 读取 token 并 `_saveSession` 回写，会把 ApiClient 会话"切走"（多账户/测试切换时）→ 修复为只更新本地 user 缓存、不动认证 token（[auth_repository.dart](../app/lib/data/repositories/auth_repository.dart)）
5. **Android 联调清单缺失**：主 manifest 无 INTERNET 权限、无明文 HTTP 允许（Android 9+ 默认禁止 http）→ `AndroidManifest.xml` 添加 `INTERNET` + `usesCleartextTraffic`（生产接 HTTPS 后应移除）
6. **真机链接**：`gradle.properties` 增加 `kotlin.incremental=false` 规避 Windows 下 Kotlin 增量缓存映射文件损坏（虚拟机/安全软件环境常见）
